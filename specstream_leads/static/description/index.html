SpecStream Leads

Create CRM leads from the rows of a finished SpecStream list. Each value keeps the page it came from.

How it works

  1. Open Settings, then SpecStream, and paste an API key from your SpecStream workspace (Agents & API).
  2. Open CRM, then Sales, then Import from SpecStream. Paste the list id and choose how many rows.
  3. Each row becomes a lead. The source URL for every value is kept in the lead description.

The module only reads finished lists, which costs nothing. It starts no search and spends no money.
