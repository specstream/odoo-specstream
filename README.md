# SpecStream for Odoo

SpecStream is the live web data engine. This module brings rows from a finished SpecStream list into Odoo CRM as leads, with the source URL of each value kept on the lead.

- `specstream_leads`: Odoo 17, depends on CRM. Add your SpecStream API key in Settings, then open CRM, Import from SpecStream.
