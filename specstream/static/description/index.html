SpecStream

The live web data engine.

One platform to build, search, extract, enrich, map, and monitor data across the entire web.

Ask for any dataset in plain words, and SpecStream builds it from the entire live web: every match found, extracted and enriched into structured records, then monitored for change. It runs through the API and MCP, and inside Sheets, CRMs, Slack, n8n, Zapier and the other tools teams already use.

What the module does

  • Creates CRM leads from the rows of a finished SpecStream list.
  • Keeps the source URL for every value in the lead description.
  • Importing a finished list costs nothing and starts no search.
  • Find rows: write what you need in everyday words, read the maximum price, and approve it. Nothing starts before you approve the price. The finished rows become leads, each value with its source URL.
  • Search the web and Extract pages call the Search API and the Extract API from CRM, then Sales. Set Speed to Fast on a search and a fast search costs $1 per 1,000; left empty, the API's default search runs.
  • Watched lists: reads a list again every hour, day or week, and records each new result, each changed value with its source URL and each result no longer in the list under CRM, then Sales, then Changes. Leads are created and updated from the same rows.
  • Scheduled runs: add the id of a schedule you approved in SpecStream, and each check reads the newest list that schedule finished. The module never creates a schedule or sets a spending limit.

How it works

  1. Open Settings, then SpecStream, and paste an API key from your SpecStream workspace (Agents & API).
  2. Open CRM, then Sales, then Import from SpecStream. Paste the id of a finished list and set the maximum number of rows.
  3. Each row becomes a lead.
  4. To build a new list, open CRM, then Sales, then Find rows (SpecStream). Write the request, choose Get the price, then Approve and start. When the list is finished, choose Create leads.
  5. To follow a list, open CRM, then Sales, then Watched lists (SpecStream). Add the list id, optionally a SpecStream schedule id, and how often to check.
